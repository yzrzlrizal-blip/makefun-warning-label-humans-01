Write the funniest single-line safety warning label that should come printed on every human being, 160 characters or fewer.

The entry:

> WARNING: This human contains 70% water, 30% unfinished projects, and 0% idea where the charger is.

## Run it

```sh
python3 main.py
```

It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), checking first that the line is one line of 1–160 characters and not only whitespace.
